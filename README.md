# pandoradocker (English)

Pandora script to retrieve all Docker information.

## Description

`pandoradocker` is a Bash script designed for use with Pandora FMS. It collects various information about the general status of Docker, images, containers, and services managed by Docker Compose, and formats them for Pandora.

## Features

- Docker service activation status.
- Total and active number of Docker images.
- Total space occupied by images and claimable space.
- Total and active number of Docker containers.
- Space occupied by containers and claimable space.
- Operational status of Docker Compose services.

## Usage

Simply run the script:

```bash
./pandoradocker
```

# pandoradocker (Français)

Script Pandora pour récupérer toutes les informations de Docker.

## Description

`pandoradocker` est un script Bash conçu pour être utilisé avec Pandora FMS. Il permet de collecter diverses informations sur l'état général de Docker, les images, les conteneurs et les services gérés par Docker Compose, puis de les formater pour Pandora.

## Fonctionnalités

- État d'activation du service Docker.
- Nombre total et actif d'images Docker.
- Taille totale occupée par les images et taille récupérable.
- Nombre total et actif de conteneurs Docker.
- Taille occupée par les conteneurs et taille récupérable.
- État de fonctionnement des services Docker Compose.

## Utilisation

Exécutez simplement le script :

```bash
./pandoradocker
```
